A Brain-Inspired Solution to Continual Learning

Functional Task Networks let one model retain different solutions, infer which one is needed, and reuse what it has learned on new problems.

FTN organizes a network into overlapping neural assemblies. A small set of examples recruits the assembly suited to the current problem, without a supplied task identity. Incompatible rules can occupy different assemblies; useful components can be shared. This handles both domain shift, where inputs change, and concept shift, where the same input needs a different answer.

Keep earlier abilities while learning new ones

Original manuscript figures: the same 16-task sequence. White means higher accuracy. Below the diagonal is retention of earlier tasks; above it is performance on tasks not yet trained.

On changing digit-classification rules, FTN retains 96% accuracy, compared with 88.6% for SupSup and 44.2% for ordinary replay. It also starts new tasks with less error than every matched comparator, including Progressive Networks and fixed-mask retrieval.

Shared-shuffle MNIST; means over five seeds, redrawn from the manuscript’s comparison table. Starting loss is measured before weight training on each new task.

Knowledge transfers in both directions

FTN achieves the lowest new-task starting loss across all three digit benchmarks. In a language-model experiment, FTN-LoRA also produces positive backward transfer: later learning improves earlier abilities. Its mean gain is 19 percentage points, while sequential LoRA and ordinary replay lose ground.

FTN can operate without replay: it reaches 94.5% accuracy on Permuted MNIST in that setting. A small, selectively replayed memory supports stronger retention when assemblies share knowledge. The main classification experiments use just 200 replay entries.
